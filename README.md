# mercado-campesino-digital
Plataforma web para la publicación de productos, reservas y reportes del Mercado Campesino Digital de Yopal.










## Estrategia de ramas

Para organizar el desarrollo del proyecto Mercado Campesino Digital de Yopal, se utilizarán las siguientes ramas:

- **principal:** contiene la versión principal y estable del proyecto.
- **desarrollo:** se utiliza para integrar los avances de programación.
- **pruebas:** se utiliza para organizar y validar las pruebas del sistema.

Esta estrategia permite organizar los cambios, detectar errores y facilitar el mantenimiento del software.
