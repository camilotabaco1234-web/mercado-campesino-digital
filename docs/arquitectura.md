# Arquitectura del sistema

Este directorio contiene la documentación de la arquitectura
del proyecto Mercado Campesino Digital de Yopal.

## Componentes principales

- Gestión de usuarios.
- Publicación de productos campesinos.
- Reservas de productos.
- Generación de reportes.

## Objetivo

Organizar la documentación técnica para facilitar el desarrollo,
las pruebas y el mantenimiento del sistema.
